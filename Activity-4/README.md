# Activity 4: Google Sheets Group Presentation

## About This Activity

This activity was a group presentation introducing Google Sheets, its basic features, and how spreadsheets can be used to organize and work with information.

## What Have I Learned?

- I learned how spreadsheet tools can help organize data, perform calculations, and present information in a structured way.
- A challenge in a group presentation is making sure the material is understandable and that the different parts fit together.
- We addressed this by organizing the presentation around the tool's features and explaining its practical uses.
- I can apply Google Sheets to organize academic information, collaborate on group tasks, and manage simple datasets, while continuing to practise formulas and data presentation.
