# Activity 2: Personal Branding

## About This Activity

This activity explored how to create a consistent personal brand through visual identity. The submitted concept develops a medical-clinic brand around the message **“Excellence in Every Care,”** using a coordinated color palette and typography.

## What Have I Learned?

- I learned how colors, fonts, and visual elements work together to communicate a brand's personality and values.
- A challenge was making the design feel professional and appropriate for a healthcare setting while still being recognizable.
- I worked through this by choosing a consistent palette and pairing typefaces with different roles to create visual hierarchy.
- I can apply these branding principles when designing future school projects, websites, and information materials, while improving by checking consistency across different formats.
