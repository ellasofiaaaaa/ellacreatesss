# Activity 6: Website Making

## About This Activity

This activity involved creating a one-page website with the help of an AI website generator. It introduced the process of turning an idea and its content into a structured online presentation.

## What Have I Learned?

- I learned how a website's sections, content, layout, and visual choices work together to create a clear user experience.
- A challenge was translating the website idea into organized content and a consistent design.
- I worked through this by defining the purpose of the page and using prompts and revisions to guide the website generator.
- I can apply this experience to future portfolio or small-business websites and improve by learning more about HTML, CSS, accessibility, and responsive design.
