# Activity 3: Social Media Infographics and Project Documentation

## About This Activity

This activity involved communicating a project through an infographic and written documentation. The project focused on climate vulnerability and crop losses, including the proposed CS-FMEWS concept.

## What Have I Learned?

- I learned how to turn project information into concise visual content and how documentation helps explain a project's purpose and ideas.
- A challenge was selecting the most important information without overcrowding the infographic or losing the context of the project.
- I addressed this by grouping related points, using a clear visual flow, and keeping the written documentation as a companion to the infographic.
- I can use these skills in future research and advocacy work, especially when explaining scientific or community-related issues to a general audience.
