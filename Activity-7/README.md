# Activity 7: Resume Generation

## About This Activity

This activity involved generating a resume with two large language models (ChatGPT and Claude) and comparing their outputs using criteria such as structure, clarity, formatting, and overall quality.

## What Have I Learned?

- I learned that AI tools can assist with drafting professional documents, but their outputs still need to be checked for accuracy, relevance, and presentation.
- A challenge was comparing the two resumes fairly instead of judging them only by personal preference.
- I addressed this by using the same prompt and reviewing both outputs against consistent criteria, including structure, clarity, formatting, and overall quality.
- I can apply this experience when preparing professional documents and improve by tailoring each resume to a specific role while verifying every detail before submitting it.
