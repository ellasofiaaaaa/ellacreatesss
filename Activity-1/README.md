# Activity 1: Presentation Design Principles

## About This Activity

This activity focused on applying presentation and visual-design principles to communicate a message clearly. The submitted work is a promotional poster for a Free Coffee activity at Ateneo de Davao University's School of Nursing, Arrupe Hall, Booth 7.

## What Have I Learned?

- I learned that an effective design needs a clear visual hierarchy, readable text, balanced composition, and colors that support the message.
- One challenge was arranging the information so the poster could catch attention while remaining easy to understand.
- I addressed this by organizing the important details, giving the main message visual emphasis, and considering spacing and readability.
- I can apply these principles to future academic presentations, posters, and infographics, and continue improving by testing designs at different screen and print sizes.
